# 隱私政策

OSM Apps 目錄自身不會儲存個人資料，然而，架站、使用量分析以及回饋的第三方服務可能如上述敘述處理與儲存資料。

## 使用量分析

這個專案使用尊重個人隱私的 [GoatCounter](https://www.goatcounter.com/) 來收集使用量數據。

你可以在 [OSM Apps
目錄使用量統計](https://osm-apps.goatcounter.com/?hl-period=month&group=day)檢視收到的數據。

## 瀏覽器端處理

有一些瀏覽器資訊，像是使用語言與平台，也許會在本地端處理來改進使用者體驗，但這些資訊不會由專案儲存或是傳送到外部伺服器。

## 架設網站

網站以 GitHub Pages 架設，根據 [GitHub
文件](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection)，GitHub
logs 訪客 IP 位址來瞭解資安要求。

要瞭解更多資訊，請檢視 [GitHub
隱私政策聲明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)。

## 回饋

這個專案使用 Formbricks Cloud 來收集透過「給予回饋意見」功能的回饋。

問卷的回應不會收集填寫者的 IP 位址、國家資訊，或是裝置資訊。你不一定要提供 email，但提供之後你可以收到專案維護者的回應。

維護者收到回應後檢視完即會刪除，刪除的回應會在 90 天後從 Formbricks 的備份永久刪除。

要瞭解更多問卷提供商如何處理資料，請檢視 [Formbricks 的隱私政策](https://formbricks.com/privacy-policy)。
